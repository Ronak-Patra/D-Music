# 🎵 D-Music

**A feature-rich Android mobile application for local and streaming audio, featuring dynamic UI, live lyrics, Spotify playlist imports, and comprehensive listening stats.**

## 📖 About The Project

**D-Music** is a highly customized and feature-expanded Android application, proudly forked from the [OpenSpot Music App](https://github.com/BlackHatDevX/openspot-music-app). Designed purely as a mobile experience for true music lovers, this app bridges the gap between local music playback and global streaming discovery. Whether you want to import your favorite Spotify playlists, track your offline listening stats, or enjoy a dynamic UI that adapts to your album art, D-Music provides a seamless, all-in-one audio environment.

## ✨ Complete Feature List

### 🎧 Playback & Library Management
* **Play Local Files:** Seamlessly scan, organize, and play all offline audio files on your device.
* **Local Music Download:** Directly download tracks to your local storage for offline listening.
* **Create New Playlists:** Easily build, edit, and manage custom playlists on the go.
* **Import from Spotify:** Connect and seamlessly transfer your existing playlists directly from Spotify.

### 🎨 Immersive Mobile UI/UX
* **Dynamic UI Change:** The application's color palette and interface dynamically shift to match the album art of the currently playing song.
* **Live Lyrics:** Sing along with synchronized, real-time lyrics for supported tracks.
* **Rotating Cover:** Enjoy a beautiful, vinyl-style rotating album cover during playback.
* **Multi-Language Support:** Fully localized interface supporting multiple languages for a global audience.

### 🌍 Discovery & Search
* **Dynamic Search:** Find exactly what you are looking for instantly with responsive search results.
* **Advanced Multiple Filters:** Narrow down your music using deep filters, including **Sub-region** and **Music Types/Genres**.
* **Smart Recommendations:** Discover new tracks through an intelligent recommendation engine based on your recently played songs.
* **Trending Charts:** Stay updated with what is popular through both **Global** and **Multiple Countries Trending** lists.

### 📊 User Analytics
* **Your Music Stats:** Keep track of your exact listening habits. View your **Recently Played** tracks and calculate your **Total Played Time**.

## 🚀 Download & Installation

The application is already built and ready to use. You can download the compiled Android package (APK) directly from this repository.

Navigate to the following path in the repository to download the release build:

📁 **[`android/app/build/outputs/apk/release/D-Music.apk`](./D%20Music/android/app/build/outputs/apk/release/D-Music.apk)**

**How to Install:**
1. Click the file path above or navigate to it in the repository, and click **Download** to save the `D-Music.apk` file to your Android device.
2. If prompted, allow installation from "Unknown Sources" in your device's security settings.
3. Install the application and open it to start listening.
