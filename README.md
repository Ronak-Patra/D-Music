# 🎵 D-Music

**A feature-rich Android mobile application for local and streaming audio, featuring dynamic UI, live lyrics, advanced JioSaavn integration, sleep timers, and comprehensive listening stats.**

## 📖 About The Project

**D-Music** is a highly customized and feature-expanded Android application, proudly forked from the [OpenSpot Music App](https://github.com/BlackHatDevX/openspot-music-app). Designed purely as a mobile experience for true music lovers, this app bridges the gap between local offline music playback and global streaming discovery via high-quality API integrations (like JioSaavn). Whether you want to explore pinpointed genre and release date filters, import your Spotify playlists, track your listening stats, or fall asleep to a built-in sleep timer, D-Music provides a seamless, all-in-one audio environment.

## ✨ Complete Feature List

### 🎧 Playback & Library Management
* **Play Local Files:** Seamlessly scan, organize, and play all offline audio files on your device.
* **Local Music Download:** Directly download high-quality streaming tracks to your local storage for offline listening.
* **Create & Manage Playlists:** Easily build, edit, and manage custom playlists on the go. Save online playlists directly to your Liked Playlists folder.
* **Import from Spotify:** Connect and seamlessly transfer your existing playlists directly from Spotify.

### 🎨 Immersive Mobile UI/UX
* **Dynamic UI Change:** The application's color palette and interface dynamically shift to match the album art of the currently playing song.
* **Live Lyrics:** Sing along with synchronized, real-time lyrics for supported tracks.
* **Rotating Cover:** Enjoy a beautiful, vinyl-style rotating album cover during playback.
* **Sleep Timer:** Fall asleep to your favorite music! Set a custom sleep timer from the player interface that automatically pauses playback when the countdown finishes.
* **Multi-Language Support:** Fully localized interface supporting multiple languages for a global audience.

### 🌍 Discovery & Search
* **Advanced Multi-Filtering:** Narrow down your music using complex combined filters, including **Sub-region** and **Music Types/Genres** (e.g. "Punjabi Rock").
* **Smart New Releases:** Discover fresh music with an intelligent engine that accurately filters out older tracks using exact release dates, ensuring you only see genuinely new drops.
* **Trending Charts:** Stay updated with what is popular through both **Global** and **Multiple Countries Trending** lists. Old viral songs are natively supported and permitted in trending.
* **Smart Recommendations:** Discover new tracks through an intelligent recommendation engine based on your recently played songs.

### 📊 User Analytics
* **Your Music Stats:** Keep track of your exact listening habits. View your **Recently Played** tracks and calculate your **Total Played Time**.

## 🚀 Download & Installation

The application is already built and ready to use. You can download the compiled Android package (APK) directly from this repository.

📁 **Download:** [Get the Latest Release](https://github.com/Ronak-Patra/D-Music/releases)

**How to Install:**
1. Click the file path above or navigate to it in the repository, and click **Download** to save the `D-Music.apk` file to your Android device.
2. If prompted, allow installation from "Unknown Sources" in your device's security settings.
3. Install the application and open it to start listening.
